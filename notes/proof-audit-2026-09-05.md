## 可运行证据

主检查（Python 3.11+，仅标准库）：

```text
python -S src/verify_paper.py
```

它重放五棵区间树、四边形系数，并对照第二套区间实现的哈希及叶子分类。

可单独运行第二套区间实现及四边形检查：

```text
python -S src/audit_intervals.py
python -S src/verify_four_cycle.py
```

第二套区间程序不导入项目中的其他模块，使用通用有理区间运算和递归树解析；它与生成证书的代码分开。报告保存每类叶子的精确最小余量，不用浮点容差通过检查。

可选的代数复算需要 SymPy 1.14.0：

```text
python src/audit_algebra.py
```

代数脚本检查 12 条多项式恒等式。它不证明符号的取值范围；上述逐项记录负责说明取值范围和因式的符号。

完整工程测试还使用已有的 NetworkX、SAT 等依赖，不是重放主定理数值证书的必要条件。测试包含损坏树、非法符号、缺节点、多节点及将目标偷换为 1/50 时必须失败的对照。
